# resources

Le `Resource` tipizzate del progetto (es. la scheda personaggio `CharacterData`) vivono come
**script** in `scripts/data/` e vengono istanziate da codice o serializzate in JSON in `data/`.
Questa cartella è pronta per ospitare istanze `.tres` salvate dall'Inspector di Godot (es. PG
predefiniti, preset di dungeon, tabelle di bilanciamento) quando/se vorrai crearne di persistenti.
